# Godot Shaders Basics

A beginner course for shaders in Godot Engine.

## Overview

Godot's shader tools are powerful, but they aim to be approachable to newcomers, with plenty of built-in variables you can modify directly, and the option to create your own complex behavior without them. This repository contains shaders which steadily include more and more of Godot's features with increasing complexity, to teach you about the capabilities of the engine.
